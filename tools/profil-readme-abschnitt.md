### GymBase

Fitness- und Trainingsplattform als lokale Web-App: Übungsdatenbank mit aufklappbaren Fotoanleitungen, eigene Sammlungen, manueller Plan-Editor, deterministischer Trainingsplan-Generator, Trainingsmodus mit Pausentimer und Fortschrittsstatistik.

**Tech:** React · TypeScript · Vite · Tailwind CSS · GSAP · Chart.js
